# Black-Artists-
505 project-Black Artists Database 
This will be making a Back Artist database. It will be a digital archive highlighting Black artists and art. The main goal is to ihave one inclusive place for black artists. Those who have contributes to politics, history, culture, music, and more. Information on some of these individuals can sometimes be hard to find so the goal is to have them all in one place. This could also be a place for people to find artists that they have never heard of before. 
I will be using HTML, CSS, JavaScript, Python, Supabase for this web application. HTML and CSS are for creating the webpage and JavaScript makes it responsive. Supabase will hold all of the artists and art and JavaScript will retrieve the information. Github will be used to store everything. This all together will complete a fully functional web application.
